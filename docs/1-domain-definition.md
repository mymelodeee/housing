## 1. 서비스 개요 및 목적

**housing**은 수도권(서울·경기·인천)에서 매매가 7~15억원 구간의 아파트를 탐색·비교하려는 실수요 매수자를 위한 부동산 분석 서비스다. 참고 서비스는 호갱노노(hogangnono.com) 수준의 시세/입지 정보 UX이며, 지도는 네이버지도 기반 UI/UX를 따른다.

핵심 목적은 다음 두 가지다.

1. **직주근접 판단**: 사용자의 근무지(삼성전자 화성·평택 캠퍼스)까지 셔틀버스 통근시간을 기준으로 후보 아파트를 걸러낸다.
2. **의사결정 지원**: 즐겨찾기한 후보들을 입지·교육·개발호재 등 다축으로 비교하고, 각 아파트별로 규제 현황과 대출 가능액을 계산해 실제 매수 가능 여부를 판단할 수 있게 한다.

본 서비스는 실제 매수 목표가(8~12억)보다 넓은 탐색 범위(7~15억)를 기본으로 노출하여, 예산 경계 부근의 대안 매물도 비교 대상에서 누락되지 않도록 한다.

## 2. 핵심 도메인 용어 정의 (Glossary)

| 용어 | 정의 |
|---|---|
| **매물(Listing)** | 지도/목록에 노출되는 개별 아파트 단지 또는 특정 동·호수 단위 판매 정보. 매매가, 면적, 위치 등을 속성으로 가짐 |
| **탐색 범위(Search Range)** | 사용자에게 노출되는 매물의 가격 필터 조건(7~15억). 실제 매수 목표가(8~12억)와는 별개의, 더 넓은 노출 기준 |
| **즐겨찾기(Favorite)** | 사용자가 관심 매물로 표시하여 별도 목록에 저장하는 행위/상태 |
| **비교셋(Comparison Set)** | 즐겨찾기 매물 중 사용자가 선택한 n개(2개 이상)를 묶어 다축 비교하는 단위 |
| **셔틀 통근시간(Shuttle Commute Time)** | 매물 위치에서 가장 가까운 삼성전자 화성/평택 캠퍼스 셔틀 정류장까지의 도보/차량 이동 거리 및 소요시간, 그리고 셔틀 탑승 후 캠퍼스 도착까지의 총 통근시간 |
| **규제지역(Regulated Area)** | 투기과열지구·조정대상지역으로 지정되어 LTV/DSR, 다주택자 대출, 세제 등이 강화 적용되는 지역 |
| **토지거래허가구역(Land Transaction Permission Zone)** | 지자체 허가 없이는 일정 면적 이상 토지·주택 거래가 제한되는 구역. 주택 매수 시 실거주 목적 확인 및 실거주 의무가 부과됨 |
| **실거주 의무(Occupancy Requirement)** | 대출 실행 또는 토지거래허가 조건으로 부과되는, 일정 기간 내 전입하여 실제 거주해야 하는 의무. 기간 미준수 시 대출 회수·허가 취소 등의 제재 대상 |
| **갭투자(Gap Investment)** | 전세보증금을 낀 매수(매매가와 전세가 차액만 자기자본으로 충당)로 실거주 없이 주택을 취득하는 방식. 토지거래허가구역 및 일부 대출 규제 하에서는 제한됨 |
| **LTV(Loan To Value, 주택담보대출비율)** | 담보(주택) 가치 대비 대출 가능 금액의 비율 |
| **DSR(Debt Service Ratio, 총부채원리금상환비율)** | 차주의 연소득 대비 모든 대출의 연간 원리금 상환액 비율. 대출 한도를 제한하는 핵심 지표 |
| **생애최초 특례(First-Time Homebuyer Benefit)** | 무주택 세대주가 생애 최초로 주택을 구입할 때 적용받는 LTV 완화, 대출한도 우대, 정책대출(디딤돌·보금자리론 등) 소득 요건 완화 혜택 |
| **대출 시나리오(Loan Scenario)** | 명의 구성(단독/부부합산), 소득, 자본금 등 입력 조건에 따라 산출되는 하나의 대출 실행 가정. 시나리오별로 최대 대출가능금액과 상환계획이 도출됨 |
| **원리금균등상환(Equal Principal & Interest Repayment)** | 대출 기간 동안 매월 동일한 금액(원금+이자)을 상환하는 방식 |

## 3. 핵심 유스케이스

### 3.1 매물 탐색 및 통근 분석
- 사용자는 지도(네이버지도 UI/UX 기반)에서 7~15억 구간의 매물을 조회한다.
- 매물별로 삼성전자 화성/평택 캠퍼스 셔틀 정류장까지의 거리 및 셔틀 통근시간이 표시된다.

### 3.2 즐겨찾기
- 사용자는 관심 매물을 즐겨찾기에 추가/제거할 수 있다.

### 3.3 비교셋 생성 및 비교
- 사용자는 즐겨찾기 중 n개를 선택해 비교셋을 만든다.
- 비교셋은 다음 축으로 매물 간 차이를 보여준다: 주변 교통(지하철/광역버스/시내버스), 상권, 학군(학교/학원가), 강남 접근성, 유흥시설·공원 유무, 삼성전자 화성/평택 셔틀 통근시간, 주변 개발 호재, 주변 일자리(대기업 등).

### 3.4 매물 상세 - 규제/대출 분석
- 매물 상세 화면은 해당 매물이 위치한 지역의 규제 현황(토지거래허가구역, 투기과열지구/조정대상지역 여부)을 표시한다.
- 규제 현황에 따라 산출된 최대 대출가능금액, 갭투자 가능 여부, 실거주 필수 기간을 표시한다.

### 3.5 매물 상세 - 입지 정보
- 비교셋과 동일한 입지 축(교통/상권/학군/강남 접근성/유흥·공원)을 개별 매물 상세에서도 단독으로 조회할 수 있다.

### 3.6 매물 상세 - 대출 시뮬레이션
- 사용자는 명의 구성(부부합산/단독), 소득, 성과금, 자본금을 입력해 대출 시나리오를 계산한다.
- 시스템은 시나리오별 최대 대출가능금액과 10/20/30년 원리금균등상환액을 산출하고, 두 시나리오를 비교해 유리한 쪽을 안내한다.

## 4. 주요 엔티티와 속성

**아파트 매물(Listing)**
- 위치(좌표/주소), 단지명, 매매가, 전용면적, 규제지역 여부, 토지거래허가구역 여부
- 최근접 삼성전자 셔틀 정류장 및 셔틀 통근시간
- 입지 속성(교통/상권/학군/강남 접근성/유흥·공원/개발호재/주변 일자리)

**사용자(User)**
- 근무지(화성/평택 캠퍼스 중 선택), 즐겨찾기 목록, 비교셋 목록
- 대출 시뮬레이션에 사용되는 개인/부부 소득·자본 정보(세션 단위 입력값, 별도 영구 저장 여부는 별도 논의 필요)

**즐겨찾기(Favorite)**
- 사용자 ID, 매물 ID, 등록일시

**비교셋(Comparison Set)**
- 사용자 ID, 포함 매물 ID 목록(n개), 생성일시

**대출 시나리오(Loan Scenario)**
- 매물(매매가), 명의 구성(단독/부부합산), 연소득, 성과금, 자본금, 생애최초 여부, 규제지역/토허구역 여부
- 산출 결과: 최대 대출가능금액, 필요 자기자본, 10/20/30년 원리금균등상환액, 실거주 의무 여부, 갭투자 가능 여부

## 5. 비즈니스 규칙

### 5.1 규제/갭투자/실거주 판단 로직

매물의 지역 규제 상태에 따라 다음 순서로 판단한다.

1. **토지거래허가구역 여부 확인**
   - 해당 시/구/동이 토지거래허가구역이면 → 매수 시 실거주 목적 확인이 필요하며, 갭투자(전세 낀 매수) **불가**로 판정한다. 실거주 의무 기간은 지자체 허가 조건(통상 2년)을 표시한다.
   - 토지거래허가구역이 아니면 → 갭투자 가능 여부는 대출 규제(5.1.2)의 실거주 의무 조건에 따른다.

2. **투기과열지구/조정대상지역(규제지역) 여부 확인**
   - 규제지역이면: LTV는 무주택자 기준 70%(생애최초 예외 적용 시 70%, 정책대출 한도 내), 유주택자는 신규 주택구입 목적 대출이 원칙적으로 제한된다. 소유권이전 조건부 전세대출(갭투자 목적 대출)은 금지되며, 주담대 실행 시 6개월 이내 전입 의무가 부과된다.
   - 비규제지역이면: 상대적으로 완화된 LTV(통상 70% 내외)가 적용되고 실거주 의무는 부과되지 않는 것을 기본값으로 한다.

3. **수도권·규제지역 공통 대출 한도 상한**
   - 규제지역 내 주택구입 목적 주담대는 명의·소득과 무관하게 **최대 6억원**을 넘을 수 없다(2025.6.28 시행 가계부채 관리 대책).

4. **최종 갭투자 가능 여부**
   - `갭투자 가능 여부 = NOT(토지거래허가구역) AND NOT(규제지역 내 주담대를 실행하는 경우)`
   - 즉, 대출을 받지 않고 전액 현금+전세보증금으로 매수하는 경우에만 규제지역이라도 실거주 의무가 대출 조건으로는 발생하지 않으나, 토지거래허가구역이면 이 경우에도 허가 조건상 실거주 의무가 적용된다.

### 5.2 최대 대출가능금액 산출 로직

최대 대출가능금액은 아래 세 가지 상한 중 **최솟값**으로 결정한다.

1. **LTV 상한액** = 매매가 × LTV비율(규제지역/생애최초 여부에 따라 40~70% 사이에서 결정)
2. **DSR 역산 상한액**: 연소득 × DSR한도(1금융권 40%, 생애최초·정책대출 등 우대 시 완화) = 허용 가능한 연간 총 원리금상환액. 이 금액을 원리금균등상환 공식(5.3)에 대입해 역산한 대출원금이 DSR 상한액이다. 기존 부채가 있다면 기존 부채의 연간 상환액을 먼저 차감한다.
3. **지역별 대출 한도 상한**: 수도권·규제지역 내에서는 6억원, 정책대출(디딤돌/보금자리론) 이용 시 해당 상품의 자체 한도(예: 생애최초 특례구입자금보증 2.4억원 등)

`최대 대출가능금액 = MIN(LTV 상한액, DSR 역산 상한액, 지역별 대출 한도 상한)`

### 5.3 원리금균등상환액 계산 로직

입력: 대출원금(P), 연 금리(r_annual), 대출기간(년, N)
처리:
- 월 금리 r = r_annual / 12
- 총 상환 개월 수 n = N × 12
- 월 상환액 PMT = P × r × (1+r)^n / ((1+r)^n − 1)
출력: 10년/20년/30년 각각의 월 상환액(PMT)과 연간 상환액(PMT × 12)

이 출력값은 5.2의 DSR 역산 계산과 5.4의 시나리오 비교에 공통으로 사용된다.

### 5.4 대출 시나리오 비교 로직 (부부합산 vs 생애최초 단독명의)

두 시나리오는 각각 5.2 로직을 통해 최대 대출가능금액을 산출한 뒤, 다음 기준으로 비교·판단한다.

**입력 차이**
- 시나리오 1(부부합산): 혼인신고 후 부부 합산 소득·자본으로 명의를 공동/단독 구성. 정책대출 이용 시 부부합산 소득 요건(예: 신혼부부 보금자리론 8,500만원 이하 등)을 충족하는지 별도 확인 필요 — 요건 초과 시 정책대출 대신 은행 자체 주담대(일반 DSR 규제만 적용)로 판단.
- 시나리오 2(생애최초 단독명의): 자본금을 한 명에게 집중하고 단독 명의로 생애최초 특례(LTV 우대, 정책대출 완화 소득 요건) 적용 가능 여부를 소득·무주택 세대주 요건 기준으로 확인.

**판단 절차**
1. 각 시나리오의 생애최초/정책대출 자격 요건(무주택 세대주 여부, 소득 상한, 규제지역 내 LTV 상한 등)을 확인한다.
2. 자격을 충족하는 시나리오에 한해 완화된 LTV·DSR·정책대출 한도를 적용하고, 미충족 시 일반 규제(5.1, 5.2)를 적용한다.
3. 두 시나리오 각각의 `최대 대출가능금액`, `필요 자기자본(매매가 − 대출액 − 기보유 현금)`, `연간 원리금상환 부담(DSR 실사용률)`을 산출한다.
4. 비교 기준: (a) 필요 자기자본이 보유 자본금 이내인지(자금 조달 가능 여부) → 불가능한 시나리오는 우선 제외, (b) 동일 조건에서 대출가능금액이 더 큰 쪽, (c) 동일 대출가능금액이면 DSR 실사용률(상환 부담)이 낮은 쪽, (d) 실거주 의무·전입 조건이 동일하게 적용되므로 이는 비교 변수에서 제외한다.
5. 위 기준을 모두 반영해 "자금 조달 가능 + 대출가능금액 최대 + 상환 부담 최소"인 시나리오를 유리한 시나리오로 판정한다.
