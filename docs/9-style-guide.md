# housing 프론트엔드 스타일 가이드

- 버전: v0.1
- 최종 수정일: 2026-07-08
- 근거: 사용자가 제공한 네이버지도 UI 캡처 이미지 분석. 지도 SDK(FE-2: 네이버지도)와 시각적으로 이질감이 없도록, 지도 화면에서 자주 보이는 "정보 밀도가 높지만 정돈된" 패턴(필 형태 필터 칩, 아이콘+라벨 조합의 플로팅 툴바, 흰색 카드가 지도 위에 뜨는 구조, 원형 배지 마커)을 앱 전체 컴포넌트 언어로 확장했다.
- 참조 문서: [4-project-principle.md](./4-project-principle.md) §6(프론트엔드 구조), FE-1 `Modal`/`Badge` 컴포넌트(이미 구현됨 — 이 문서의 토큰을 적용해 구체적인 색/여백 값을 채우는 대상)
- 버전 관리 규칙: 본 문서를 수정할 때마다 상단 버전과 최종 수정일을 함께 갱신하고 변경이력에 기록한다.
- 적용 범위: 이 문서는 **디자인 토큰과 컴포넌트 패턴**만 정의한다. 실제 화면 구성(어떤 데이터를 어디에 배치할지)은 각 FE-N Task의 완료 조건과 `docs/8-wireframe.md`를 따른다. 오버엔지니어링 금지 원칙에 따라 이 프로젝트(개인용 단일 사용자 웹앱) 규모를 넘는 디자인 시스템(테마 빌더, 다중 브랜드 대응 등)은 포함하지 않는다.

## 1. 디자인 원칙

1. **정보 밀도 우선, 장식 최소화**: 원본 이미지처럼 아이콘+짧은 한글 라벨 조합으로 기능을 압축 표시한다. 불필요한 장식(그라디언트, 화려한 애니메이션)을 넣지 않는다.
2. **흰 카드가 지도/배경 위에 뜬다**: 모든 패널·툴바·모달은 옅은 그림자를 가진 흰색(다크모드: 짙은 회색) 카드로, 배경과 명확히 분리된다.
3. **원형/필 형태 위주**: 필터·상태 표시는 필(pill) 또는 원형 배지로, 카드/패널은 큰 라운드 모서리로 통일한다.
4. **색은 의미로만 사용**: 색상은 브랜드 장식이 아니라 카테고리 구분·상태 전달(성공/경고/확인필요 등) 목적으로만 쓴다.
5. **라이트/다크 모두 대응**: FE-9(실거래가 그래프) 등 dataviz 스킬 요구사항과 맞춰, 모든 색 토큰은 라이트/다크 페어로 정의한다.

## 3. 타이포그래피

- 폰트 스택: `Pretendard, -apple-system, "Malgun Gothic", sans-serif` — 한글 라벨이 짧고 조밀하게 배치되는 캡처 이미지 스타일에 맞춰 자간이 좁고 가독성 높은 국문 산세리프를 우선한다. (실제 폰트 파일을 프로젝트에 추가하는 것은 이 문서 범위 밖이며, 웹폰트 도입 여부는 해당 FE Task 수행 시점에 별도 결정한다 — 우선은 시스템 폰트로 폴백해도 무방하다.)

| 토큰 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| `--font-size-xs` | 12px | 400 | 마커 라벨, 캡션, 배지 텍스트 |
| `--font-size-sm` | 13px | 400/500 | 필터 칩 라벨, 툴바 버튼 라벨, 보조 텍스트 |
| `--font-size-base` | 15px | 400 | 본문 |
| `--font-size-lg` | 17px | 600 | 카드 제목, 매물 카드 매매가 |
| `--font-size-xl` | 22px | 700 | 화면 타이틀 |

## 4. 여백 · 모서리 반경 · 그림자

캡처 이미지의 필터 칩(완전 라운드)과 우측 툴바(둥근 사각형), 지도 타입 썸네일(중간 라운드)에서 3단계 반경 체계를 도출했다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--radius-full` | 999px | 필터 칩, 배지, 마커 |
| `--radius-lg` | 16px | 카드, 모달, 지도 타입 썸네일 |
| `--radius-md` | 10px | 툴바 버튼, 입력 필드 |
| `--radius-sm` | 6px | 인라인 요소(작은 태그) |

| 토큰 | 값 |
|---|---|
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-5` | 24px |
| `--space-6` | 32px |

| 토큰 | 값 | 용도 |
|---|---|---|
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,0.06)` | 필터 칩, 마커 라벨 |
| `--shadow-md` | `0 2px 8px rgba(0,0,0,0.10)` | 카드, 툴바, 지도 타입 스위처 |
| `--shadow-lg` | `0 8px 24px rgba(0,0,0,0.16)` | 모달(FE-1 `Modal`) |

다크모드에서는 그림자 대신(혹은 함께) `--color-border`를 사용한 1px 테두리로 요소를 구분한다(어두운 배경 위 그림자는 시각적으로 약해지므로).

## 5. 컴포넌트 패턴

### 5.1 필터 칩 (Filter Chip)

캡처 이미지 상단 "음식점 / 카페 / 팝업스토어…" 버튼 패턴. FE-3(매물 탐색 필터), FE-4(즐겨찾기 탭 전환)에서 사용.

- 형태: `--radius-full`, `--color-surface` 배경, `--color-border` 1px 테두리, `--shadow-sm`.
- 내부: 좌측 원형 아이콘(카테고리 강조색 배경 + 흰 아이콘) + 우측 `--font-size-sm` 라벨.
- 선택 상태: 배경 `--color-primary-soft`, 텍스트/테두리 `--color-primary`.
- 비활성 상태: `--color-text-disabled`, 클릭 불가.

### 5.2 플로팅 툴바 버튼 (Floating Toolbar Button)

캡처 이미지 우측 세로 툴바(테마/저장/거리뷰 등, 아이콘 위 작은 라벨) 패턴. FE-2(지도 확대/축소, 반경 등 지도 컨트롤)에서 사용.

- 형태: `--radius-md`, `--color-surface` 배경, `--shadow-md`, 세로로 아이콘 + `--font-size-xs` 라벨 스택.
- 여러 버튼을 세로로 이어붙일 때는 버튼 사이 1px `--color-border` 구분선만 넣고 각 버튼 자체는 모서리를 개별적으로 두지 않는다(캡처 이미지처럼 하나의 카드 안에 구획만 나눔).

### 5.3 지도 마커 (Map Marker)

캡처 이미지의 원형 아이콘 마커(회색/유채색 원 + 흰 아이콘) 패턴. FE-2/FE-3에서 사용.

- 기본: 28px 원형, `--color-accent-blue` 배경, 흰색 집 아이콘, `--shadow-sm`.
- 즐겨찾기된 매물/단지: 배경 `--color-primary`.
- 마커 라벨(단지명 등)은 흰 배경 + 짙은 텍스트의 작은 필 형태로 마커 아래 배치, 지도 위에서도 가독성 유지(`--shadow-sm` 필수).

### 5.4 카드 (Card)

매물 카드(FE-3), 단지 카드(FE-4), 비교셋 열(FE-5) 등 공통.

- `--radius-lg`, `--color-surface` 배경, `--shadow-md`, 내부 패딩 `--space-4`.
- 카드 안에서 강조 수치(매매가 등)는 `--font-size-lg`/`700`, 보조 정보는 `--font-size-sm`/`--color-text-secondary`.

### 5.5 배지 (Badge) — FE-1 구현 완료, 이 문서 기준 색상만 적용

- `default` variant: `--color-surface-muted` 배경, `--color-text-secondary` 텍스트.
- `needs-confirmation`("확인필요", FE-7) variant: `--color-warning` 배경(연한 톤 `color-mix` 또는 15% 불투명도), `--color-warning` 텍스트/테두리.

### 5.6 모달 (Modal) — FE-1 구현 완료, 이 문서 기준 색상만 적용

- `--radius-lg`, `--color-surface` 배경, `--shadow-lg`, 반투명 backdrop `rgba(0,0,0,0.4)`(다크모드 동일 — backdrop은 라이트/다크 구분 없이 항상 어둡게).
- "중복입니다"(FE-5), "비교셋 최대 5개" 등 경고성 모달은 제목 텍스트에 `--color-danger` 또는 `--color-warning` 강조.

### 5.7 탭 (Tab) — FE-6(매물 상세 공통 셸), FE-4(즐겨찾기)에서 사용

- 선택된 탭: 하단 2px `--color-primary` 밑줄 + `--color-text-primary` 텍스트.
- 비선택 탭: `--color-text-secondary`, 밑줄 없음.
- 탭 전환 시 로딩/에러는 탭 콘텐츠 영역에서만 표시되고 탭 자체(헤더)는 항상 상호작용 가능해야 한다(FE-6 완료 조건: 한 탭 실패가 다른 탭을 막지 않음).

## 6. 다크모드 원칙

- `prefers-color-scheme` 미디어쿼리를 기본 신호로 사용하고, 앱 자체 라이트/다크 토글 UI는 이번 스코프(F1~F7)에 없으므로 별도로 구현하지 않는다(오버엔지니어링 금지) — 시스템 설정을 그대로 따른다.
- 모든 색 토큰은 위 표의 라이트/다크 값을 CSS 커스텀 프로퍼티로 정의하고, `@media (prefers-color-scheme: dark)`에서 다크 값으로 교체하는 방식을 기본으로 한다.
- FE-9(실거래가 변동 그래프)는 dataviz 스킬 가이드에 따라 라이트/다크 모두에서 그래프 라인/축 색상이 `--color-text-secondary` 대비 기준을 만족해야 한다.

## 7. 접근성

- 지도 마커 라벨, 배지 텍스트 등 작은 텍스트(`--font-size-xs`)는 배경 대비 WCAG AA(4.5:1) 이상을 유지한다.
- 모든 인터랙티브 요소(칩, 탭, 버튼)는 키보드 포커스 시 `--color-primary` 2px 아웃라인을 표시한다.
