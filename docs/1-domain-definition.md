## 1. 서비스 개요 및 목적

**housing**은 수도권(서울·경기·인천)에서 매매가 7~15억원 구간의 아파트를 탐색·비교하려는 실수요 매수자를 위한 부동산 분석 서비스다. 참고 서비스는 호갱노노(hogangnono.com) 수준의 시세/입지 정보 UX이며, 지도는 네이버지도 기반 UI/UX를 따른다.

핵심 목적은 다음 두 가지다.

1. **직주근접 판단**: 사용자의 근무지(삼성전자 화성·평택 캠퍼스)까지 셔틀버스 통근시간을 기준으로 후보 아파트를 걸러낸다.
2. **의사결정 지원**: 즐겨찾기한 후보들을 입지·교육·개발호재·연식·재건축 등 다축으로 비교하고, 각 매물별로 규제 현황과 대출 가능액을 계산해 실제 매수 가능 여부를 판단할 수 있게 한다.

본 서비스는 실제 매수 목표가(8~12억)보다 넓은 탐색 범위(7~15억)를 기본으로 노출하여, 예산 경계 부근의 대안 매물도 비교 대상에서 누락되지 않도록 한다.

> **아파트 단지 vs 매물**: 사용자는 "동탄역 시범 우남퍼스트빌"처럼 하나의 **아파트 단지(Apartment Complex)** 자체를 비교 대상으로 삼을 수도 있고, 그 단지 안의 특정 판매 건(**매물, Listing** — 매매가·전용면적이 서로 다른 개별 거래 건)을 비교 대상으로 삼을 수도 있다. 연식·리모델링·재건축·주변 재개발·입지·규제지역 여부 등은 모두 "단지" 단위 속성이며, 매매가·전용면적은 "매물" 단위 속성이다.

> **대출 계산 범위 한정**: 본 서비스의 대출 시뮬레이션은 시중은행 자체 주택담보대출(LTV/DSR 기준)만을 다룬다. 디딤돌대출·보금자리론 등 정책모기지 상품은 소득·주택가액 요건이 별도 법령으로 자주 개정되고 신청 절차가 상이하여 본 서비스의 계산 범위에서 제외한다(§7 범위 밖 참조).

## 2. 핵심 도메인 용어 정의 (Glossary)

| 용어 | 정의 |
|---|---|
| **아파트 단지(Apartment Complex)** | 지도/목록에 노출되는 상위 단위. 단지명, 위치, 연식, 리모델링 이력, 재건축 추진현황, 주변 재개발 정보, 규제지역·토지거래허가구역 여부, 셔틀 정보, 입지 속성 등 "위치·건물 자체"에 종속된 속성을 가진다. 하나의 단지는 여러 매물을 가질 수 있다 |
| **매물(Listing)** | 특정 아파트 단지에 속한 **개별 판매 건**. 매매가, 전용면적 등 "거래 건"에 종속된 속성을 가지며 반드시 하나의 단지(Apartment Complex)에 속한다(단지 FK 필수) |
| **연식(Building Age)** | 단지의 준공년도를 기준으로 산출되는 경과년수. 준공년도는 저장하고 연식은 조회 시점 기준으로 계산되는 표시값이다(저장하지 않음) |
| **리모델링 이력(Remodeling History)** | 단지의 리모델링 사업 추진 여부(해당없음/추진중/완료)와, 완료된 경우 완료 연도 |
| **재건축 추진현황(Reconstruction Status)** | 단지의 재건축 사업 진행 단계(해당없음/추진위원회/조합설립인가/사업시행인가/관리처분인가/이주철거중/착공) |
| **주변 재개발 정보(Nearby Redevelopment Info)** | 단지 인근 지역의 정비사업(재개발) 추진 현황에 대한 설명. 교통·일자리 등 포괄적 호재를 뜻하는 "개발호재"와 달리, 노후 주거지 정비사업(재개발구역 지정, 조합설립 등)에 한정된 정보 |
| **탐색 범위(Search Range)** | 사용자에게 노출되는 매물의 가격 필터 조건(7~15억). 실제 매수 목표가(8~12억)와는 별개의, 더 넓은 노출 기준 |
| **즐겨찾기(Favorite)** | 사용자가 관심 대상(아파트 단지 또는 매물)을 표시하여 별도 목록에 저장하는 행위/상태. 단지 즐겨찾기와 매물 즐겨찾기는 서로 독립된 목록이다 |
| **비교셋(Comparison Set)** | 즐겨찾기한 대상 중 사용자가 선택한 2개 이상, 최대 5개 이하를 묶어 다축 비교하는 단위. 비교 대상 유형(**단지 비교** 또는 **매물 비교**) 중 하나를 생성 시 선택하며, 하나의 비교셋 내 대상은 동일 유형이어야 한다(단지와 매물을 한 비교셋에 섞지 않음). 매물 비교는 같은 단지의 매물끼리든 서로 다른 단지의 매물끼리든 모두 가능하다 |
| **셔틀 통근시간(Shuttle Commute Time)** | 단지 위치에서 가장 가까운 삼성전자 화성/평택 캠퍼스 셔틀 정류장까지의 이동 거리(500m 이하는 도보, 초과는 차량 기준) 및 소요시간, 그리고 셔틀 탑승 후 캠퍼스 도착까지의 총 통근시간 |
| **규제지역(Regulated Area)** | 투기과열지구·조정대상지역으로 지정되어 LTV/DSR, 다주택자 대출, 세제 등이 강화 적용되는 지역. 단지가 위치한 지역 단위로 판단되는 속성이다 |
| **토지거래허가구역(Land Transaction Permission Zone)** | 지자체 허가 없이는 일정 면적 이상 토지·주택 거래가 제한되는 구역. 주택 매수 시 실거주 목적 확인 및 실거주 의무가 부과됨(단지 위치 기준 속성) |
| **실거주 의무(Occupancy Requirement)** | 대출 실행 또는 토지거래허가 조건으로 부과되는, 일정 기간 내 전입하여 실제 거주해야 하는 의무. 기간 미준수 시 대출 회수·허가 취소 등의 제재 대상 |
| **갭투자(Gap Investment)** | 전세보증금을 낀 매수(매매가와 전세가 차액만 자기자본으로 충당)로 실거주 없이 주택을 취득하는 방식. 토지거래허가구역 및 일부 대출 규제 하에서는 제한됨 |
| **LTV(Loan To Value, 주택담보대출비율)** | 담보(주택) 가치 대비 대출 가능 금액의 비율 |
| **DSR(Debt Service Ratio, 총부채원리금상환비율)** | 차주의 연소득 대비 모든 대출의 연간 원리금 상환액 비율. 대출 한도를 제한하는 핵심 지표 |
| **주택 보유 구분(Housing Ownership Tier)** | 세대 기준으로 무주택 / 1주택 / 다주택(2주택 이상)을 구분하는 분류. **주거용으로 실사용 중인 오피스텔 1채는 1주택 보유로 산정**하되, 이 자체로는 다주택자에 해당하지 않는다 |
| **생애최초 특례(First-Time Homebuyer Benefit)** | 세대 구성원 전원이 무주택인 세대주가 생애 최초로 주택을 구입할 때, 시중은행 자체 주담대에서 적용받는 LTV 완화 혜택. 세대원(배우자 포함) 중 1인이라도 주택(주거용 오피스텔 포함)을 보유하면 대상에서 제외된다 |
| **대출 시나리오(Loan Scenario)** | 명의 구성(단독/부부합산), 소득, 자본금, 세대의 기존 주택 보유 현황과 특정 매물의 매매가·소속 단지의 규제 정보를 조합해 산출되는 하나의 대출 실행 가정. 시나리오별로 최대 대출가능금액과 상환계획이 도출됨. 로그인 없이 단일 사용자 프로필에 영구 저장되며 "내 정보" 화면에서 수정 가능 |
| **원리금균등상환(Equal Principal & Interest Repayment)** | 대출 기간 동안 매월 동일한 금액(원금+이자)을 상환하는 방식 |
| **매매가 변동 이력(Price History)** | **아파트 단지**의 과거 실거래 매매가·거래일자 시계열. 국토교통부 아파트 실거래가 공개시스템(오픈API)을 출처로 하며, 조회 시점 기준 최근 20년을 기본 기간으로 함. 개별 매물이 아닌 단지 단위로 관리한다(국토부 실거래가 데이터 자체가 단지+거래건 단위로 공개되며, 특정 판매 건 하나에 종속되는 값이 아니기 때문) |
| **단지 시세(Complex Price Range)** | 단지 비교 시 사용되는 대표 시세. 해당 단지에 속한 매물들의 매매가 중 최솟값~최댓값(및 평균)으로, 별도 저장하지 않고 조회 시점에 계산한다(§5.5) |

## 3. 핵심 유스케이스

### 3.1 매물 탐색 및 통근 분석
- 사용자는 지도(네이버지도 UI/UX 기반)에서 7~15억 구간의 매물을 조회한다. 지도 핀/카드에는 매물의 매매가·전용면적과 함께, 소속 단지의 연식·셔틀 통근시간 등이 함께 표시된다.
- 매물별로(소속 단지 기준) 삼성전자 화성/평택 캠퍼스 셔틀 정류장까지의 거리 및 셔틀 통근시간이 표시된다.
- 조회 조건(가격/지역 등)에 해당하는 매물이 없으면, 지도/목록 영역에 **"조건에 맞는 매물이 0건입니다"**를 표시한다(별도 에러가 아닌 정상 상태로 처리).

### 3.2 즐겨찾기
- 사용자는 관심 있는 **아파트 단지** 또는 **매물**을 각각 즐겨찾기에 추가/제거할 수 있다. 단지 즐겨찾기와 매물 즐겨찾기는 서로 다른 목록으로 관리된다.

### 3.3 비교셋 생성 및 비교
- 사용자는 비교 대상 유형(**단지 비교** 또는 **매물 비교**)을 선택한 뒤, 해당 유형의 즐겨찾기 중 2~5개를 선택해 비교셋을 만든다.
  - **단지 비교**: 서로 다른 단지끼리 비교. 그 단지의 기본정보(연식, 리모델링 이력, 재건축 추진현황, 주변 재개발 정보)와 단지 시세(§2, §5.5)로 비교한다.
  - **매물 비교**: 매물끼리 비교. 서로 다른 단지에 속한 매물 간 비교도, 동일 단지에 속한 매물끼리의 비교도 모두 가능하다. 매물 자체 속성(매매가, 전용면적)과 함께 소속 단지의 기본정보도 함께 비교 축에 포함된다.
- 비교셋은 다음 축으로 차이를 보여준다: 연식, 리모델링 이력, 재건축 추진현황, 주변 재개발 정보, 주변 교통(지하철/광역버스/시내버스), 상권, 학군(학교/학원가), 강남 접근성, 유흥시설·공원 유무, 삼성전자 화성/평택 셔틀 통근시간, 주변 개발 호재, 주변 일자리(대기업 등), 그리고 (단지 비교 시) 단지 시세 또는 (매물 비교 시) 매매가·전용면적.
- 이미 포함된 대상(단지 또는 매물)을 동일 비교셋에 다시 추가하려는 시도는 "중복입니다" 팝업을 띄우고 추가하지 않는다(중복 불가).

### 3.4 매물 상세 - 규제/대출 분석
- 매물 상세 화면은 해당 매물이 속한 **단지**의 규제 현황(토지거래허가구역, 투기과열지구/조정대상지역 여부)을 표시한다.
- 규제 현황과 매물의 매매가를 기준으로 산출된 최대 대출가능금액, 갭투자 가능 여부, 실거주 필수 기간을 표시한다.

### 3.5 매물 상세 - 입지 정보
- 비교셋과 동일한 입지 축(교통/상권/학군/강남 접근성/유흥·공원)과 단지 기본정보(연식/리모델링/재건축/주변 재개발 정보)를 개별 매물 상세에서도 단독으로 조회할 수 있다(소속 단지 기준 조회).

### 3.6 매물 상세 - 대출 시뮬레이션
- 회원가입/로그인 절차 없이, **앱 최초 진입 시** 명의 구성(부부합산/단독), 소득, 성과금, 자본금, **세대의 기존 주택 보유 현황(무주택 / 배우자 1인이 주거용 오피스텔 1채 보유 등)**을 입력받으며, 이 값은 기기/앱의 단일 사용자 프로필로 영구 저장된다.
- 사용자는 "내 정보" 화면(마이페이지와 동일한 UX 패턴)에서 위 입력값을 언제든 재입력/수정할 수 있으며, 수정 즉시 대출 시뮬레이션 결과가 최신값 기준으로 재계산된다.
- 시스템은 저장된 입력값과 매물의 매매가, 소속 단지의 규제 정보를 기반으로 매물 상세 화면에서 시나리오별 최대 대출가능금액과 10/20/30년 원리금균등상환액을 산출하고, 두 시나리오를 비교해 유리한 쪽을 안내한다.

### 3.7 매물 상세 - 매매가 변동 이력
- 단지에 법정동코드·국토부 단지명이 매핑되어 있으면, 매물 상세 화면은 국토교통부 아파트 실거래가 공개시스템(오픈API)을 **매 요청마다 실시간 조회(fetch-through, 저장하지 않음)**하여 매매가 변동 그래프를 표시한다. 이 API는 월 단위로만 개별 조회가 가능한 특성상, 조회 범위를 **최근 3년(36개월)**로 한정한다.
- 매핑 정보가 없는 단지는 로컬에 저장된 실거래 데이터를 사용하며, 이 경우에는 기존 방식대로 **최근 20년간**(20년 미만이면 **최초 거래 시점 이후**) 매매가 변동 그래프·테이블을 표시한다.
- 실거래 데이터가 전혀 없는 단지(예: 분양권 단계)는 "실거래 이력 없음"을 표시한다.

### 3.7.1 매물 상세 - 입지 속성 (700m 반경 기준)
- **학군**: 단지로부터 700m 이내 최근접 초등학교의 이름과 거리(m)를 표시한다. data.go.kr "전국초중등학교위치표준데이터"(정적 데이터셋, 실시간 API 아님)를 사전에 로컬 테이블로 임포트한 뒤 조회 시점에 haversine 거리 계산으로 최근접 학교를 산정한다. **API 활용신청 승인 대기 중**이라 현재는 시드 데이터가 비어 있어 전량 "정보 없음"으로 표시된다.
- **강남 접근성**: 단지 좌표와 강남역 좌표 간 **직선거리(좌표 거리)**만 표시한다. 대중교통 소요시간 계산은 네이버클라우드플랫폼 지도 API가 대중교통 경로를 지원하지 않아 이번 범위에서 보류한다(추후 ODsay·TMAP 등 별도 API 검토 필요).
- **유흥시설 유무**: 소상공인시장진흥공단 상권정보 API(`storeListInRadius`)로 단지 좌표 기준 700m 반경을 실시간 조회하여 유흥주점업 표준산업분류코드 4종(`I21101`/`I21102`/`I21103`/`I21109`) 중 하나라도 매물이 있으면 "있음"으로 판별한다. 지정값(552201~552206)과 `I56211~I56213` 형식은 실제 API 응답에서 상시 결과없음을 반환함이 실측으로 확인되어, 강남역 좌표 700m 반경 실조회로 실제 결과가 반환되는 것을 확인한 `I21101` 계열 코드로 확정했다.
- **공원**: 이번 연동 범위에서 제외한다(패스). "정보 없음"으로 유지된다.

학군/강남접근성/유흥은 자동 산정값(실데이터 연동, §3.7.1 참조)으로 채워지고, 나머지(교통/상권/개발호재/주변일자리)와 공원은 수동 입력값이며 값이 없으면 "정보 없음"으로 표시된다.

## 5. 비즈니스 규칙

### 5.1 규제/갭투자/실거주 판단 로직

매물이 속한 **단지**의 규제 속성을 기준으로 판단한다.

1. **토지거래허가구역 여부 확인**
   - 매물이 속한 단지가 위치한 시/구/동이 토지거래허가구역이면 → 매수 시 실거주 목적 확인이 필요하며, 갭투자(전세 낀 매수) **불가**로 판정한다. 실거주 의무 기간은 지자체 허가 조건(기본값 2년, 지자체 고시로 개별 확인)을 표시한다.
   - 토지거래허가구역이 아니면 → 실거주 의무는 5.1.2의 규제지역 주담대 조건에 따른다.

2. **투기과열지구/조정대상지역(규제지역) 여부 확인**
   - 단지가 규제지역 내에 있고 해당 매물에 주담대를 실행하는 경우, 다주택자는 신규 주택구입 목적 대출이 **금지**(LTV 0%)되고, 소유권이전 조건부 전세대출(갭투자 목적 대출)도 금지된다. 주담대 실행 시 **6개월 이내 전입 의무**가 부과된다.
   - 비규제지역이면 실거주 의무는 부과되지 않는다(기본값).

3. **주택 보유 구분별 LTV 확정표**

   | 세대 주택 보유 구분 | 규제지역 LTV | 비규제지역 LTV |
   |---|---|---|
   | 무주택 - 생애최초 해당 | 70% | 80% |
   | 무주택 - 생애최초 미해당 | 40% | 70% |
   | 1주택(주거용 오피스텔 1채 포함, 처분조건부 가정) | 40% | 70% |
   | 다주택(2주택 이상) | 신규 주담대 불가 (0%) | 60% |

   (2025.6.28·9.7 가계부채 관리 대책 기준. 2026.6.30 대책으로 화성시 동탄구·용인시 기흥구 등 규제지역이 추가 지정되었으나 LTV 수치 자체의 변경은 없음)

   - 배우자 1인이 주거용 오피스텔 1채를 보유한 세대는 "1주택" 행을 적용하며, "다주택" 행은 적용하지 않는다.
   - **1주택 항목의 "처분조건부" 가정**: 2025.6.28 대책 이후 1주택 세대는 원칙적으로 신규 주택구입 목적 주담대가 금지되며, 기존 주택을 대출 실행일로부터 6개월 이내 처분하는 조건(처분조건부 약정)일 때만 무주택 세대와 동일한 기준으로 대출이 실행된다. 본 서비스는 처분조건부 이행을 전제로 무주택-미해당과 동일 LTV를 적용하며, 처분조건부를 이행하지 않을 경우의 대출 금지 상태는 별도로 모델링하지 않는다(단순화, §5.4 대출 시나리오와 동일 전제).
   - 규제지역 내 신규 주택구입 목적 주담대는 매매가 구간별로 한도가 세분화되어 있으나(15억원 이하 6억원 / 15억~25억원 4억원 / 25억원 초과 2억원, 2025.10.15 대책), 본 서비스의 매물 매매가 범위(7~15억원, §2 참조)는 전부 "15억원 이하" 구간에 해당하므로 §5.1.4의 "6억원 고정 상한"으로 단순화해도 실질적으로 동일하다.

4. **수도권·규제지역 공통 대출 한도 상한**
   - 규제지역 내 단지의 매물에 대한 주택구입 목적 주담대는 명의·소득과 무관하게 **최대 6억원**을 넘을 수 없다(2025.6.28 시행 가계부채 관리 대책).

5. **최종 갭투자 가능 여부**
   - `갭투자 가능 여부 = NOT(토지거래허가구역) AND NOT(규제지역 내 주담대를 실행하는 경우)`
   - 대출 없이 전액 현금+전세보증금으로 매수하는 경우, 토지거래허가구역이 아니라면 실거주 의무가 발생하지 않는다. 토지거래허가구역이면 대출 여부와 무관하게 허가 조건상 실거주 의무가 적용된다.

### 5.2 최대 대출가능금액 산출 로직

최대 대출가능금액은 아래 세 가지 상한 중 **최솟값**으로 결정한다.

1. **LTV 상한액** = 매물의 매매가 × LTV비율(5.1.3 표, 소속 단지의 규제지역 여부로 결정) − 기존 주담대 잔액(있는 경우)
2. **DSR 역산 상한액**: (연소득 + 연 환산 성과금) × DSR한도(1금융권 40%) = 허용 가능한 연간 총 원리금상환액. 이 금액을 원리금균등상환 공식(5.3)에 대입해 역산한 대출원금이 DSR 상한액이다. 기존 부채가 있다면 기존 부채의 연간 상환액을 먼저 차감한다.
3. **지역별 대출 한도 상한**: 소속 단지가 수도권·규제지역 내에 있으면 6억원

`최대 대출가능금액 = MIN(LTV 상한액, DSR 역산 상한액, 지역별 대출 한도 상한)`

### 5.3 원리금균등상환액 계산 로직

입력: 대출원금(P), 연 금리(r_annual), 대출기간(년, N)
처리:
- 월 금리 r = r_annual / 12
- 총 상환 개월 수 n = N × 12
- 월 상환액 PMT = P × r × (1+r)^n / ((1+r)^n − 1)
출력: 10년/20년/30년 각각의 월 상환액(PMT)과 연간 상환액(PMT × 12)

이 출력값은 5.2의 DSR 역산 계산과 5.4의 시나리오 비교에 공통으로 사용된다.

### 5.4 대출 시나리오 비교 로직 (부부합산 vs 단독명의)

**공통 전제**: 두 시나리오 모두 부부 중 1인(배우자)이 주거용 오피스텔 1채를 보유하고 있다고 가정한다. 이에 따라 세대 주택 보유 구분은 명의 구성과 무관하게 **"1주택"**으로 고정되며, 어느 시나리오도 생애최초 특례 대상이 되지 않는다(생애최초 특례는 세대원 전원이 무주택인 경우에만 적용). 따라서 본 비교는 순수하게 **명의 구성에 따른 LTV·DSR 여력 차이**만을 비교한다.

**입력 차이**
- 시나리오 1(부부합산): 혼인신고 후 부부 합산 소득(연봉 7천만원 × 2인)·성과금(1인당 1억원 × 2인)·자본금(2.5억원)으로 명의를 공동 구성. 세대 주택 보유 구분: 1주택.
- 시나리오 2(단독명의): 오피스텔을 보유하지 않은 배우자 앞으로 자본금을 몰아(5억원) 단독 명의로 진행. 연소득 7천만원, 성과금 1억원은 해당 배우자 1인 기준으로만 산정. 세대 주택 보유 구분은 동일하게 1주택(명의자 개인은 무주택이나, 세대 기준 판단이므로 생애최초 미적용).

**판단 절차**
1. 두 시나리오 모두 5.1.3 표의 "1주택" LTV(규제지역 50% / 비규제지역 60%)를 적용한다.
2. 5.2 로직으로 각 시나리오의 최대 대출가능금액을 산출한다. DSR 역산 시 시나리오 1은 부부 합산 소득, 시나리오 2는 단독 소득을 사용한다.
3. 두 시나리오 각각의 `최대 대출가능금액`, `필요 자기자본(매매가 − 대출액 − 보유 자본금)`, `연간 원리금상환 부담(DSR 실사용률)`을 산출한다.
4. 비교 기준: (a) 필요 자기자본이 보유 자본금 이내인지(자금 조달 가능 여부) → 불가능한 시나리오는 제외, (b) 자금 조달이 가능한 시나리오 중 대출가능금액이 더 큰 쪽, (c) 대출가능금액이 동일하면 DSR 실사용률이 더 낮은 쪽을 선택, (d) (a)~(c)가 모두 동일하면 부부합산 시나리오를 기본 우선으로 한다(공동 명의가 향후 1주택 추가 대출 여력 산정에서 유리하기 때문).
5. 위 기준을 모두 반영해 "자금 조달 가능 + 대출가능금액 최대 + 상환 부담 최소"인 시나리오를 유리한 시나리오로 판정한다.

### 5.5 비교 데이터 산출 규칙 (단지 비교 vs 매물 비교)

- **단지 비교**일 때 "단지 시세"는 저장된 값이 아니라, 해당 단지에 속한 매물들의 매매가를 조회 시점에 집계(MIN/MAX, 필요 시 AVG)하여 계산한다. 해당 단지에 매물이 1건도 없으면 시세는 "매물 없음"으로 표시한다.
- **단지 비교**의 나머지 축(연식, 리모델링, 재건축, 주변 재개발 정보, 입지 축, 셔틀 통근시간)은 단지(4.1) 데이터를 그대로 사용한다.
- **매물 비교**일 때는 비교 대상 매물 각각의 매매가·전용면적(4.2)과, 그 매물이 속한 단지의 연식/리모델링/재건축/주변 재개발 정보/입지 축(4.1)을 함께 조합해 비교 데이터를 구성한다. 동일 단지에 속한 매물끼리 비교하는 경우 단지 축(연식 등)은 모든 대상에서 동일하게 표시된다(정상 동작이며 오류가 아니다).

## 7. 범위 밖(Out of Scope) 명시

본 도메인 정의서는 요구사항에 명시된 항목만을 다룬다. 다음은 이번 버전에 포함하지 않는다: 데이터베이스 스키마, API 명세, UI 와이어프레임/목업, 코드 구현, 다중 사용자/회원가입·로그인 인증 체계(본 서비스는 회원 인증 없이 단일 사용자 프로필만 사용), 실제 정책 수치의 실시간 자동 갱신 방식, 디딤돌대출·보금자리론 등 정책모기지 계산 로직, 요구사항-기능-테스트 간 추적 ID 체계, 동·호수 단위의 개별 매물 상세 관리(전용면적·매매가 수준까지만 다룸). 단지 시세(§4·§5.5)는 비영속(계산값)이며 별도 테이블로 저장하지 않는다는 점도 이번 버전 원칙에 포함된다. 강남 접근성의 대중교통 소요시간 계산, 공원 유무 판별은 이번 버전 범위에서 제외한다(§3.7.1). 필요 시 별도 문서로 후속 정의한다.

### 7.1 알려진 미해결 이슈 (실데이터 연동, 2026-07-10 기준)
- **학군 정보 미채움**: 초중등학교 위치 표준데이터 API의 data.go.kr 활용신청 승인이 완료되지 않아, 승인 전까지 모든 단지의 학군 정보가 "정보 없음"으로 표시된다.
- **국토부 실거래가 API 미검증**: 이 프로젝트의 개발 환경에서는 아웃바운드 네트워크 제약으로 국토부 API 호출이 403으로 차단되어, 3개 실제 단지(동탄역시범우남퍼스트빌/힐스테이트고덕센트럴/힐스테이트구성)의 법정동코드·단지명 매칭 여부가 실증되지 않았다. 인터넷 접근이 가능한 실제 배포 환경에서 재검증이 필요하다.
- **공동주택 단지 목록제공 서비스 미검증**: 세대수 연동의 1단계로 구현한 `apt-list-api.repository.js`/`apt-list.service.js`(`getLegaldongAptList`, `lawdCd` 파라미터, `kaptCode`/`kaptName` 응답 필드)는 리서치로 확인한 스펙을 기반으로 작성했으나, 이 개발 환경에서 4가지 엔드포인트/파라미터 조합을 실호출해본 결과 전부 `500 Unexpected errors`가 반환되어 실증하지 못했다. 국토부 실거래가 API(1613000)는 403으로, 상권정보 API(B553077)는 정상 동작하는 것과 비교하면 이 환경은 `apis.data.go.kr`를 전면 차단하는 것이 아니라 일부 국토부 org ID(1611000/1613000 계열)만 선택적으로 차단하는 것으로 추정된다. 실제 배포 환경에서 파라미터명·응답 필드명 재검증이 필요하다.
