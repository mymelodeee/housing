## 0. 문서 목적 및 범위

본 문서는 [1-domain-definition.md](./1-domain-definition.md)(v0.8)의 도메인 규칙과 [2-prd.md](./2-prd.md)(v0.6)의 기능 요구사항(F1~F7)을 실제 사용자 흐름으로 구체화한다. 각 시나리오는 Given(전제조건)-When(사용자 행동)-Then(시스템 반응/결과) 형식을 따르며, 구체적 예시(매물명, 금액, 날짜)를 사용한다.

이 문서는 DB 스키마, API 명세, UI 목업을 다루지 않는다(도메인 정의서 §7, PRD §10과 동일하게 범위 밖으로 유지). 등장하는 사용자는 서비스 목표 사용자인 "삼성전자 화성/평택 캠퍼스 근무, 수도권 8~12억 아파트 매수를 준비 중인 부부"이며, 별도 로그인 없이 단일 사용자 프로필로 앱을 사용한다.

## 1. F1. 매물 탐색 및 셔틀 통근 분석

### 시나리오 1-1 (핵심). 조건에 맞는 매물을 지도에서 탐색한다

- **Given**: 사용자가 앱을 실행하고 지도 화면(네이버지도 UI/UX 기반)에서 매매가 필터를 "7억~15억"으로 설정했다. 근무지는 "삼성전자 화성 캠퍼스"로 선택되어 있다.
- **When**: 사용자가 동탄신도시 일대를 지도에서 확대해 조회한다.
- **Then**: "동탄역 시범 우남퍼스트빌"(매매가 9억 5천만원, 전용 84.98m²)을 포함한 매물 카드들이 지도 핀과 목록에 표시된다. 각 카드에는 매물 자체 속성(매매가, 전용면적)과 함께, 소속 단지("동탄역 시범 우남퍼스트빌")의 최근접 셔틀 정류장("동탄역 셔틀정류장", 350m, 도보)과 셔틀 통근시간(42분)이 함께 노출된다.

### 시나리오 1-2 (예외). 조건에 맞는 매물이 0건이다

- **Given**: 사용자가 매매가 필터를 "14억~15억"으로 좁히고, 지역을 "인천 강화군"으로 지정했다.
- **When**: 사용자가 조회를 실행한다.
- **Then**: 시스템은 에러 화면이 아닌 정상 상태로 "조건에 맞는 매물이 0건입니다" 메시지를 지도/목록 영역에 표시한다. 필터 조정 버튼은 계속 사용 가능하다.

### 시나리오 1-3 (예외). 셔틀 배차 정보를 확보하지 못한 매물이 표시된다

- **Given**: "힐스테이트 평택 지제역"(매매가 8억 8천만원)은 평택 캠퍼스 인근에 위치하지만, 소속 단지 기준으로 sbus.u-vis.com(삼성전자 통근버스 포털)에서 해당 지역 정류장 배차 정보를 아직 수집하지 못한 상태다.
- **When**: 사용자가 해당 매물 카드를 지도/목록에서 조회한다.
- **Then**: 매물 카드의 셔틀 통근시간 항목(소속 단지 기준)에는 "정보 없음"이 표시된다. 매매가, 전용면적, 위치 등 다른 정보는 정상적으로 표시되며, 매물 탐색·즐겨찾기·비교셋 등 나머지 기능 이용에는 지장이 없다(블로킹 아님).

## 2. F2. 즐겨찾기

### 시나리오 2-1 (핵심). 관심 단지와 관심 매물을 각각 즐겨찾기에 추가한다

- **Given**: 사용자가 지도 화면에서 "동탄역 시범 우남퍼스트빌" 단지 카드와, 그 안의 매매가 9억 5천만원(전용 84.98m²) 매물 카드를 보고 있다.
- **When**: 사용자가 단지 카드의 즐겨찾기(하트) 아이콘을 탭하고, 이어서 매물 카드의 즐겨찾기 아이콘도 탭한다.
- **Then**: 단지 카드의 아이콘이 활성 상태로 전환되며 "동탄역 시범 우남퍼스트빌" 단지가 **단지 즐겨찾기** 목록에 즉시 추가된다. 매물 카드의 아이콘도 별도로 활성 상태로 전환되며, 해당 매물이 **매물 즐겨찾기** 목록에 즉시 추가된다. 두 목록은 서로 독립적으로 관리되며, 단지 즐겨찾기에 추가했다고 해서 그 단지의 매물이 매물 즐겨찾기에 자동으로 추가되지는 않는다.

### 시나리오 2-2 (예외). 동일 단지/동일 매물을 중복으로 즐겨찾기하지 않는다

- **Given**: "동탄역 시범 우남퍼스트빌"이 이미 단지 즐겨찾기에, 그 안의 매매가 9억 5천만원 매물이 이미 매물 즐겨찾기에 각각 등록되어 있다(두 하트 아이콘 모두 활성 상태).
- **When**: 사용자가 활성화된 단지 즐겨찾기 아이콘을 다시 탭하고, 별도로 활성화된 매물 즐겨찾기 아이콘도 다시 탭한다.
- **Then**: 단지 즐겨찾기와 매물 즐겨찾기가 각각 독립적으로 해제(토글 OFF)되며, 새로운 즐겨찾기 항목이 추가되지 않는다. 단지 즐겨찾기는 항상 단지당 1개 상태(등록/해제), 매물 즐겨찾기는 항상 매물당 1개 상태(등록/해제)로만 존재한다.

## 3. F3. 비교셋 생성 및 비교

비교셋은 생성 시 비교 대상 유형(**단지 비교** 또는 **매물 비교**)을 먼저 선택한다. 아래 3-1~3-3은 **매물 비교** 모드 기준 시나리오이고, 3-4는 **단지 비교** 모드, 3-5는 **동일 단지 내 매물 비교**(매물 비교 모드의 특수 케이스) 시나리오다.

### 시나리오 3-1 (핵심). 매물 비교 모드로 즐겨찾기 매물 3개를 비교셋으로 묶어 다축 비교한다

- **Given**: 사용자가 비교 대상 유형으로 "매물 비교"를 선택했다. 사용자의 매물 즐겨찾기 목록에 다음 3개 매물이 있다.
  - A. "동탄역 시범 우남퍼스트빌"(화성, 9억 5천만원)
  - B. "힐스테이트 평택 지제역"(평택, 8억 8천만원)
  - C. "e편한세상 용인 한숲시티"(용인 기흥, 10억 2천만원)
- **When**: 사용자가 매물 즐겨찾기 화면에서 A, B, C를 체크박스로 선택하고 "비교하기" 버튼을 누른다.
- **Then**: 비교셋 화면에 3개 매물이 나란히 배치되고, 매물 자체 속성(매매가·전용면적)과 각 매물이 속한 단지의 기본정보를 조합해 다음 축별로 값이 표로 비교된다.
  - 매매가/전용면적: A 9억 5천만원/84.98m² / B 8억 8천만원/미상 / C 10억 2천만원/미상
  - 연식(소속 단지 준공년도 기준): A 2021년 준공(5년차) / B 2018년 준공(8년차) / C 2019년 준공(7년차)
  - 리모델링 이력(소속 단지): A "해당없음" / B "해당없음" / C "해당없음"
  - 재건축 추진현황(소속 단지): A "해당없음" / B "해당없음" / C "해당없음"
  - 주변 재개발 정보(소속 단지): A "정보 없음" / B "정보 없음" / C "정보 없음"
  - 셔틀 통근시간: A 42분 / B 정보 없음(§1-3 참조) / C 55분
  - 주변 교통(지하철/광역버스/시내버스): A "동탄역 SRT·GTX 예정, 광역버스 다수" / B "지제역 SRT, 시내버스" / C "정보 없음"(공공데이터 미확보)
  - 상권: A "상 (동탄역 인근 상업지구)" / B "중" / C "정보 없음"
  - 학군: A "중 (동탄중, 학원가 형성 중)" / B "정보 없음" / C "상 (한숲시티 학군 특화 단지)"
  - 강남 접근성: A "차량 45분" / B "차량 65분" / C "차량 50분"
  - 유흥시설·공원 유무: A "공원 인접, 유흥시설 없음" / B "정보 없음" / C "호수공원 인접"
  - 개발 호재: A "GTX-A 동탄역 개통 예정" / B "정보 없음" / C "정보 없음"
  - 주변 일자리: A "삼성전자 화성캠퍼스 인접" / B "삼성전자 평택캠퍼스 인접" / C "정보 없음"
  사용자는 이 표를 통해 셔틀 통근시간은 A가 가장 짧고, 학군은 C가 우위이며, B는 다수 항목이 데이터 미확보 상태임을 한눈에 확인할 수 있다.

### 시나리오 3-2 (예외). 비교셋 매물 개수 제한을 벗어난다

- **Given**: 사용자가 "매물 비교" 모드를 선택했고, 매물 즐겨찾기 목록에 6개 이상의 매물이 있다.
- **When (Case 1)**: 사용자가 6개째 매물을 체크박스로 선택하려 시도한다.
- **Then (Case 1)**: 시스템은 6번째 선택을 막고 "비교셋은 최대 5개까지 선택할 수 있습니다" 안내 메시지를 표시한다.
- **When (Case 2)**: 사용자가 1개 매물만 선택한 상태에서 "비교하기" 버튼을 누른다.
- **Then (Case 2)**: 비교 화면으로 진입하지 않고, "비교하려면 2개 이상 선택해야 합니다" 안내 메시지가 표시된다.

### 시나리오 3-3 (예외). 이미 포함된 매물을 같은 비교셋에 다시 추가하려 한다

- **Given**: 사용자가 "매물 비교" 모드로 "동탄역 시범 우남퍼스트빌"의 매물(A), "힐스테이트 평택 지제역"의 매물(B)로 비교셋을 이미 만들어 두었다.
- **When**: 사용자가 해당 비교셋 화면에서 매물 추가 기능으로 A를 다시 선택해 추가하려 시도한다.
- **Then**: 시스템은 "중복입니다" 팝업을 띄우고 A를 비교셋에 다시 추가하지 않는다. 비교셋은 기존 A, B 2개 매물 상태 그대로 유지된다(DB `comparison_set_listings` 테이블의 (comparison_set_id, listing_id) UNIQUE 제약이 최종 방어선).

### 시나리오 3-4 (신규, 핵심). 단지 비교 모드로 서로 다른 단지 3곳을 비교한다

- **Given**: 사용자가 비교 대상 유형으로 "단지 비교"를 선택했다. 사용자의 단지 즐겨찾기 목록에 다음 3개 단지가 있다.
  - A. "동탄역 시범 우남퍼스트빌"(화성, 2021년 준공) — 이 단지에 속한 매물들의 매매가는 9억 5천만원~10억 3천만원
  - B. "힐스테이트 평택 지제역"(평택, 2018년 준공) — 이 단지에 속한 매물들의 매매가는 8억 2천만원~8억 8천만원
  - C. "e편한세상 용인 한숲시티"(용인 기흥, 2019년 준공) — 이 단지에 속한 매물들의 매매가는 9억 8천만원~10억 5천만원
- **When**: 사용자가 단지 즐겨찾기 화면에서 A, B, C를 체크박스로 선택하고 "비교하기" 버튼을 누른다.
- **Then**: 비교셋 화면에 3개 단지가 나란히 배치되고, 매물 개별 속성(매매가·전용면적) 대신 단지 기본정보와 "단지 시세"로 비교된다.
  - 연식: A 2021년 준공(5년차) / B 2018년 준공(8년차) / C 2019년 준공(7년차)
  - 리모델링 이력: A "해당없음" / B "해당없음" / C "해당없음"
  - 재건축 추진현황: A "해당없음" / B "해당없음" / C "해당없음"
  - 주변 재개발 정보: A "정보 없음" / B "정보 없음" / C "OO구역 재개발 정비사업 조합설립인가 단계(2025)"
  - 단지 시세(해당 단지 소속 매물들의 매매가 MIN~MAX, 조회 시점 집계값): A "9.5억~10.3억" / B "8.2억~8.8억" / C "9.8억~10.5억"
  - 셔틀 통근시간 등 나머지 입지 축도 §3.3 표준 축과 동일하게 함께 표시된다.
  사용자는 이 표를 통해 단지 연식은 A가 가장 신축이고, 단지 시세 범위는 C가 가장 높으며, 재개발 이슈는 C 인근에만 있음을 한눈에 확인할 수 있다. 단지 시세는 저장된 값이 아니라 조회 시점에 매물 매매가를 집계해 계산된 값이다.

### 시나리오 3-5 (신규, 핵심). 동일 단지 내 서로 다른 매물끼리 비교한다

- **Given**: 사용자가 "매물 비교" 모드를 선택했다. "동탄역 시범 우남퍼스트빌" 단지 안에 전용 84.98m²/매매가 9억 5천만원 매물(A)과 전용 59.92m²/매매가 8억원 매물(B), 두 개의 서로 다른 매물이 매물 즐겨찾기에 등록되어 있다.
- **When**: 사용자가 매물 즐겨찾기 화면에서 A, B를 선택하고 "비교하기" 버튼을 누른다.
- **Then**: 비교셋 화면에 A, B 두 매물이 나란히 배치된다.
  - 매매가: A 9억 5천만원 / B 8억원 (서로 다름)
  - 전용면적: A 84.98m² / B 59.92m² (서로 다름)
  - 연식(소속 단지 기준): A 2021년 준공(5년차) / B 2021년 준공(5년차) (동일하게 표시)
  - 리모델링 이력(소속 단지 기준): A "해당없음" / B "해당없음" (동일하게 표시)
  - 재건축 추진현황(소속 단지 기준): A "해당없음" / B "해당없음" (동일하게 표시)
  - 주변 재개발 정보(소속 단지 기준): A "정보 없음" / B "정보 없음" (동일하게 표시)
  - 셔틀 통근시간 등 나머지 입지 축(소속 단지 기준)도 A, B 모두 동일하게 표시된다.
  두 매물이 같은 단지에 속하므로 단지 기반 축(연식/리모델링/재건축/재개발정보/입지)은 모두 동일하게 표시되고, 매물 자체 속성인 매매가·전용면적만 서로 다르게 표시된다. 이는 정상 동작이며 오류가 아니다(도메인 §5.5 참조).

## 4. F4. 매물 상세 - 규제/대출 분석

### 시나리오 4-1 (핵심). 규제지역 매물의 규제 현황과 대출 한도를 확인한다

- **Given**: 매매가 10억 2천만원 매물이 속한 단지 "e편한세상 용인 한숲시티"(용인 기흥)는 2026.7.1부로 투기과열지구로 신규 지정된 지역에 위치한다. 사용자는 무주택 세대주이며 생애최초 특례 대상이 아니다(§도메인 5.1.3 "무주택-생애최초 미해당" 행 적용).
- **When**: 사용자가 이 매물의 상세 화면에서 "규제/대출" 탭을 연다.
- **Then**: 화면에 소속 단지가 "투기과열지구 지정 지역"임이 표시되고, 토지거래허가구역은 아님을 명시한다. LTV 60%(규제지역, 무주택-생애최초 미해당) 적용, 규제지역 6억원 한도 상한(도메인 §5.1.4) 반영 결과 최대 대출가능금액은 매물 매매가 기준 MIN(10.2억×60%=6.12억, DSR 역산액, 6억) 중 6억원으로 산출되어 표시된다. 갭투자는 규제지역 주담대 실행 시 금지되므로 "갭투자 불가"로 표시되고, 대출 실행 시 "6개월 이내 전입 의무"가 안내된다.

### 시나리오 4-2 (예외). 규제지역 여부가 미확정인 단지의 매물(평택)을 조회한다

- **Given**: 매매가 8억 8천만원 매물이 속한 단지 "힐스테이트 평택 지제역"(평택)은 검색 시점 기준 규제지역 지정 여부가 국토교통부 고시로 확정되지 않은 상태다(도메인 §6 참조).
- **When**: 사용자가 이 매물의 상세 화면에서 "규제/대출" 탭을 연다.
- **Then**: 소속 단지의 토지거래허가구역 여부 항목에 "확인필요" 배지가 표시된다. 대출가능금액은 과대평가를 방지하기 위해 비규제지역 LTV(하한값, 무주택-생애최초 미해당 기준 70%)를 임시 적용해 산출되며, "본 금액은 규제지역 지정 확정 전 임시 산출값이며, 국토교통부 고시 확정 시 갱신됩니다"라는 안내 문구가 함께 표시된다.

## 5. F5. 매물 상세 - 입지 정보

### 시나리오 5-1 (핵심). 개별 매물의 입지 정보를 소속 단지 기준으로 조회한다

- **Given**: 사용자가 매물 즐겨찾기에 담긴 매물 중 "동탄역 시범 우남퍼스트빌" 단지의 매물 상세 화면에 들어왔다.
- **When**: 사용자가 "입지 정보" 탭을 연다.
- **Then**: 비교셋(F3)과 동일한 축인 연식(2021년 준공, 5년차), 리모델링 이력(해당없음), 재건축 추진현황(해당없음), 주변 재개발 정보(정보 없음), 교통(동탄역 SRT·GTX-A 예정, 광역버스 다수), 상권(상), 학군(중, 동탄중·학원가 형성 중), 강남 접근성(차량 45분), 유흥시설·공원 유무(공원 인접, 유흥시설 없음)가 소속 단지 기준으로 이 매물 하나에 대해서만 상세히 표시된다.

### 시나리오 5-2 (예외). 입지 데이터가 일부 누락된 단지의 매물을 조회한다

- **Given**: "e편한세상 용인 한숲시티" 단지는 소상공인시장진흥공단 상권정보·학교알리미 등 공공데이터 연동이 아직 일부만 완료되어, 상권·개발호재·주변 일자리 데이터가 채워지지 않은 상태다.
- **When**: 사용자가 이 단지에 속한 매물의 "입지 정보" 탭을 연다.
- **Then**: 소속 단지 기준으로 학군(상, 한숲시티 학군 특화 단지)과 강남 접근성(차량 50분)은 정상 표시되고, 상권·개발호재·주변 일자리 항목은 각각 "정보 없음"으로 표시된다. 화면 전체는 정상 렌더링되며 오류가 발생하지 않는다.

## 6. F6. 매물 상세 - 대출 시뮬레이션

### 시나리오 6-1 (핵심). 부부합산 vs 단독명의 대출 시나리오를 비교한다

- **Given**: 사용자는 앱 최초 진입 시 "내 정보" 화면에서 다음을 입력해 프로필에 저장했다.
  - 세대 주택 보유 구분: "1주택(배우자 소유 주거용 오피스텔 1채)" — 생애최초 특례 대상 아님
  - 연소득: 부부 각 7,000만원(합산 1억 4천만원)
  - 성과금(연 환산): 부부 각 1억원(합산 2억원)
  - 자본금(가용 현금): 2억 5천만원
  사용자가 "동탄역 시범 우남퍼스트빌"(매매가 9억 5천만원, 비규제지역 가정) 상세 화면의 "대출 시뮬레이션" 탭을 연다.
- **When**: 시스템이 저장된 프로필 값을 바탕으로 시나리오 1(부부합산)과 시나리오 2(단독명의, 자본금을 오피스텔 미보유 배우자 앞으로 5억원 몰아 단독 진행, 해당 배우자 개인 소득 7천만원·성과금 1억원만 반영)을 자동 산출한다.
- **Then**: 두 시나리오 모두 "1주택" LTV(비규제지역 60%)가 적용된다.
  - 시나리오 1(부부합산): LTV 상한액 = 9.5억×60% = 5.7억원. DSR 역산 상한액은 부부 합산 연소득(1.4억)+성과금(2억)=3.4억원을 기준으로 산출되어 LTV 상한액보다 크므로, 최대 대출가능금액은 5.7억원. 필요 자기자본 = 9.5억 − 5.7억 − 보유 자본금 2.5억 = 1.3억원 부족 → 조달 불가능(보유 자본금 2.5억으로는 부족분 충당 불가).
  - 시나리오 2(단독명의): LTV 상한액 동일 5.7억원. DSR 역산 상한액은 단독 소득(7천만원)+성과금(1억원)=1.7억원 기준으로 산출되어 시나리오 1보다 낮은 대출가능금액(예: 4.5억원)으로 제한된다고 가정 시, 필요 자기자본 = 9.5억 − 4.5억 − 자본금 5억 = 0원(조달 가능).
  - 판정 절차(도메인 §5.4)에 따라 "자금 조달 가능 여부"를 우선 적용한 결과, 조달 불가능한 시나리오 1은 제외되고 조달 가능한 시나리오 2가 "유리한 시나리오"로 안내된다. 화면에는 두 시나리오의 최대 대출가능금액, 10/20/30년 원리금균등상환액, 필요 자기자본이 나란히 표시되고 "단독명의 시나리오가 자금 조달 가능 조건을 충족해 유리합니다" 안내 문구가 노출된다.
  - (참고: 실제 산출값은 도메인 §5.2~§5.3의 정확한 DSR 역산·PMT 계산식에 따라 결정되며, 본 시나리오의 금액은 로직 적용 결과를 보이기 위한 예시다.)

### 시나리오 6-2 (예외). "내 정보"를 아직 입력하지 않은 상태에서 대출 시뮬레이션 탭을 연다

- **Given**: 사용자가 앱을 처음 설치해 아직 "내 정보"(재무 프로필)를 입력하지 않았다.
- **When**: 사용자가 "힐스테이트 평택 지제역" 상세 화면에서 "대출 시뮬레이션" 탭을 연다.
- **Then**: 대출 시뮬레이션 영역에는 계산 결과 대신 "대출 시뮬레이션을 이용하려면 내 정보를 입력해주세요"라는 입력 유도 화면과 "내 정보 입력하기" 버튼이 표시된다. 같은 매물 상세 화면의 다른 탭(규제/대출 현황 중 규제 여부, 입지 정보, 매매가 변동 이력 등 F1~F5, F7에 해당하는 정보)은 정상적으로 조회할 수 있다.

## 7. F7. 매물 상세 - 단지 단위 20년 매매가 변동 이력

### 시나리오 7-1 (핵심). 20년 이상 실거래 데이터가 있는 단지의 이력을 조회한다

- **Given**: 매물이 속한 단지 "동탄역 시범 우남퍼스트빌"은 2006년부터 현재까지 20년 이상의 국토교통부 실거래가 데이터를 보유하고 있다(매매가 변동 이력은 매물이 아닌 소속 단지 단위로 관리된다).
- **When**: 사용자가 매물 상세 화면에서 "매매가 변동 이력" 탭을 연다.
- **Then**: 소속 단지 기준 최근 20년(2006-07~2026-07) 구간의 연도별 매매가 추이 그래프가 표시되고, 최근 거래인 2024-11-02, 9억 2천만원 거래 등 세부 데이터가 출처 "국토교통부 아파트 실거래가 공개시스템(오픈API)"과 함께 테이블로 표시된다. 동일 단지의 다른 매물 상세 화면에서 이 탭을 열어도 동일한 단지 이력이 표시된다.

### 시나리오 7-2 (예외). 실거래 데이터가 20년 미만인 신축 단지를 조회한다

- **Given**: 매물이 속한 단지 "e편한세상 용인 한숲시티"는 2019년 입주한 신축 단지로, 실거래 데이터가 2019-03부터 2026-07까지(약 7년)만 존재한다.
- **When**: 사용자가 이 매물의 "매매가 변동 이력" 탭을 연다.
- **Then**: 소속 단지 기준으로 그래프와 테이블은 보유한 전체 데이터(2019-03~2026-07)만으로 표시되며, 화면 상단에 "최초거래(2019-03) 이후 데이터" 안내 문구가 함께 노출된다.

### 시나리오 7-3 (예외). 실거래 데이터가 전혀 없는 분양권 단계 단지의 매물을 조회한다

- **Given**: 매물이 속한 단지 "힐스테이트 평택 브레인시티"(가칭, 분양권 단계)는 아직 입주 전이라 실거래 이력이 전혀 없다.
- **When**: 사용자가 이 매물의 "매매가 변동 이력" 탭을 연다.
- **Then**: 소속 단지 기준으로 그래프와 테이블 대신 "실거래 이력 없음" 메시지가 표시되고, 매물 상세 화면의 다른 탭(규제/대출, 입지 정보 등)은 정상적으로 이용할 수 있다.

## 8. 범위 밖(Out of Scope) 명시

본 시나리오 문서는 도메인 정의서 §7, PRD §10과 동일하게 다음을 다루지 않는다: DB 스키마, API 명세, UI 와이어프레임/목업, 코드 구현, 회원 인증 체계, 정책모기지(디딤돌대출·보금자리론) 계산 로직, 다중 기기 동기화, 요구사항-기능-테스트 추적 ID 체계. 본 문서에 등장하는 매물명·금액·데이터 값은 시나리오 이해를 돕기 위한 예시이며 실제 매물 정보가 아니다.
